# Пара · системные Часы (Android 10+)

Установи APK версии 2 поверх версии 1. Подпись и имя пакета совпадают, привязка сохраняется. Версия 2 больше не воспроизводит звук сама. После обновления проверь первый будильник в штатных «Часах», особенно если ранее рассчитывал на звонок версии 1.

1. В профиле «Пары» открой «Будильник и дорога», включи подъём и выбери «Время по парам». Для каждой строки задай начало и время подъёма. Новые строки добавляются кнопкой «Добавить пару».
2. Нажми «Привязать будильник телефона к расписанию». Для новой привязки введи адрес HTTPS и одноразовый код в APK. Для уведомлений об изменении времени разреши уведомления. Проверка выполняется примерно раз в 15 минут с учётом энергосбережения Android.
3. Когда придёт расчёт, нажми «Открыть штатные Часы». Выбери первый будильник сверху, включи его и установи время. Проверь дату следующего звонка и параметры повтора. Мелодия, вибрация и громкость настраиваются в системных «Часах».
4. Вернись в приложение и нажми «Я сохранил изменение в Часах». Профиль покажет твоё подтверждение. Переход в «Часы» сам по себе не подтверждает установку.

Публичный Android API не даёт выбрать или изменить первый элемент списка, а SET_ALARM может создать дубликат. Поэтому универсальный вариант открывает список через ACTION_SHOW_ALARMS и предлагает ручное изменение. Производитель определяет порядок отображения. Помощнику не нужны Accessibility, root, чтение экрана и разрешение на точные будильники. При свободном дне по умолчанию предлагается оставить будильник как есть; можно включить предложение отключить его. При сбое сети параметры часов остаются прежними.

Устройство получает только дату, действие и время. Запросы и ответы подписаны, ключ защищён Android Keystore. Код привязки действует пять минут. В профиле можно отозвать доступ. Если временный адрес туннеля сменился, отключи телефон в APK и повтори привязку. Для автоматической синхронизации удобнее постоянный HTTPS-домен.

Для сборки нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажи ANDROID_HOME и выполни `sh android/build.sh`. Подпиши APK локально через apksigner.
