# «Пара · Будильник» для Android 10 и новее

1. Установи подписанный APK из релиза репозитория на свой Honor. При необходимости разреши установку из выбранного источника на время установки.
2. В личном чате открой **Настройки → ⏰ Будильник** и включи будильник. В Mini App те же параметры находятся в профиле. Выбери «Привязать Honor».
3. В приложении сначала разреши уведомления, затем точные будильники. Вставь HTTPS-адрес и пяти­минутный одноразовый код. Нажми «Привязать и проверить», затем «Проверить звук». Проверь громкость канала будильников и разрешение будильников в режиме «Не беспокоить».
4. Телефон получает только решения на сегодня и завтра по Москве. Время установлено локально через Android AlarmManager. После успешного применения бот показывает время последнего ответа телефона. Уже назначенный звонок работает без интернета. Остановить его можно действием в уведомлении либо в приложении. Длительность звонка ограничена пятью минутами.
5. Android получает обновления через JobScheduler с периодом 15 минут. Система может отложить работу при энергосбережении. Если MagicOS задерживает проверки, разреши приложению работу в фоне в настройках запуска приложений. Кнопка «Проверить расписание» обновляет данные сразу. После принудительной остановки приложения открой его снова. Перед первым учебным днём проверь звонок на своём телефоне.

Для очных занятий точное правило времени имеет приоритет. В остальных случаях вычитаются время сборов и дорога до корпуса. Для онлайна используется отдельный запас. При совпадающих первых парах выбирается более ранний подъём. Пустой подтверждённый день отменяет учебный будильник. Пропуск даты, ошибка источника или расписание старше двух часов сохраняют имеющееся решение. При включённом будильнике бот проверяет расписание хотя бы раз в десять минут.

Адрес для телефона должен оставаться доступным. Если временный Cloudflare-туннель сменит адрес, выпусти новый код и повтори привязку. Для постоянной работы используй стабильный HTTPS-домен.

## Защита

Приложение не получает токен Telegram, сессию ИТМО, тексты писем и названия предметов. Устройство использует отдельный ключ и проверяет подписанный ответ сервера для конкретного запроса. Материал ключа на телефоне зашифрован AES-GCM с Android Keystore. HTTP, автоматические перенаправления и резервное копирование приложения отключены. На хосте данные привязки в SQLite являются секретом. Администратор хоста имеет к ним доступ. Приложение не запрашивает Accessibility, root, контакты, доступ к внешним файлам или администрирование устройства.

«Отозвать доступ» в боте блокирует дальнейший обмен. Для немедленной отмены уже установленных локальных звонков на самом телефоне выбери «Отключить этот телефон». При удалении приложения Android удалит его будильники. Если телефон остаётся онлайн, можно сперва выключить будильник в боте, дождаться подтверждения отмены и затем отозвать доступ.

## Сборка

Требуются JDK 17, Android SDK Platform 35, Build Tools 35.0.0 и zip. Задай ANDROID_HOME и выполни `sh android/build.sh`. Полученный para-unsigned.apk следует подписать локально утилитой apksigner. Храни постоянный ключ подписи отдельно от репозитория и сервера бота. Обновления APK должны использовать тот же ключ.
