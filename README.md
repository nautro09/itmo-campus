# Пара · личный кампус ИТМО

Telegram-бот и Mini App с одной базой для одного студента. Персональное расписание загружается из my.itmo после входа через официальный ИТМО ID. Номер учебной группы указывать не нужно.

## Что умеет

- Свежие пары на сегодня и завтра, утренняя рассылка в 07:30 МСК и отслеживание замен на семь дней. По умолчанию проверка каждую минуту. Частоту и время можно изменить. При сбое сохраняются дата проверки и предыдущая версия.
- Дедлайны с категориями, напоминаниями, подзадачами и фильтрами. Завершение можно отменить в карточке задания. Задания, созданные в Telegram и Mini App, попадают в один список.
- Черновик из пересланного текста, подписи к медиа или письма. Локальный разбор распознаёт «завтра», дни недели, даты, время и маркированные шаги. Проверь предложенные поля перед сохранением. Если даты нет, выбери срок.
- «Пора выходить» для первой очной пары дня. Включи в настройках и укажи типичное время дороги. В профиле Mini App можно задать отдельное время для каждого корпуса. Пересчёт учитывает актуальное начало и адрес пары.
- Сводка на семь дней по кнопке и обзор следующей календарной недели по воскресеньям после 18:00 МСК. Для каждого дня видны число пар, число сдач и открытые задания.
- Два источника писем — внутренние входящие ИСУ и выбранная папка почтового ящика через IMAP. Бот пересылает текст новых сообщений в привязанный личный чат. В Mini App можно прочитать письмо и превратить его в задание.
- Пять экранов Mini App, три темы («Бумага», «Полночь», «Шалфей»), профиль с ФИО и номером ИСУ, статусы ИТМО, ИСУ, почты и Telegram. Основные действия доступны и с клавиатуры чата.

## Посмотреть интерфейс без аккаунтов

В каталоге репозитория запусти `python3 -m http.server 8080 --bind 127.0.0.1 --directory web` и открой `http://127.0.0.1:8080/?demo=1`. В профиле переключаются темы. Демоверсия использует вымышленные данные в браузере. Производственный сервер запускается командой `python bot.py` и раздаёт только три файла интерфейса.

## Запуск для себя

Понадобятся Python 3.9+, Chromium из Playwright и постоянное подключение к интернету. На Mac запусти в папке проекта команду `sh Запустить.command`. В распакованном архиве проекта файл также можно открыть двойным нажатием. При первом запуске он создаёт локальный `.env`, при следующем — устанавливает зависимости и запускает бота. Для терминала на macOS/Linux:

```sh
umask 077
cp -n .env.example .env
chmod 600 .env
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

1. Создай бота через [@BotFather](https://t.me/BotFather) и введи его токен в локальный `BOT_TOKEN` внутри `.env`. При переходе с первой версии перенеси токен из `data/telegram-token` в `.env`. Сохрани папку `data/` для переноса прежних заданий, подзадач и расписания.
2. Запусти `.venv/bin/python bot.py`. Открой бота в Telegram и введи разовый код из терминала. Вместо кода можно заранее указать свой числовой `OWNER_TELEGRAM_ID`. Для уже привязанной базы он должен совпадать с владельцем.
3. Открой **Настройки → Войти в my.itmo**. В отдельном Chromium войди в аккаунт на официальной странице ИТМО ID. Через подтверждённый сеанс бот загрузит расписание и доступные поля имени и номера ИСУ.
4. Чтобы получать внутренние письма, нажми **Почта → Войти в ИСУ**. В открывшемся окне выбери **Сообщения → Входящие**. Это отдельный вход, со своим профилем Chromium. При истечении сеанса кнопка позволяет войти повторно.
5. Для открытия Mini App из Telegram укажи публичный HTTPS-адрес приложения в `MINI_APP_URL` и перезапусти бота. Он сам установит кнопку **Открыть Пару** в меню чата. Для личного доступа используется подписанный Telegram запуск через эту кнопку. Сервер проверяет подпись, срок запуска (1 час) и ID владельца. После истечения срока открой приложение заново. [Документация Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)

## Как подключить обычную почту

Если хватает внутренних входящих ИСУ, поля IMAP можно оставить пустыми. Для второго источника задай в `.env` адрес IMAP-сервера, имя пользователя, папку и способ входа.

- Для ящика с паролем приложения укажи `IMAP_HOST`, `IMAP_USER` и `IMAP_PASSWORD`. Используется IMAP через TLS, обычно порт 993. Для Яндекс 360 сервер `imap.yandex.ru`; включи IMAP и создай пароль приложения в аккаунте Яндекса.
- Для Microsoft 365 укажи `IMAP_HOST=outlook.office365.com`, `IMAP_USER`, `MS_TENANT_ID` и `MS_CLIENT_ID`. В Microsoft Entra для зарегистрированного публичного клиента должны быть разрешены device code flow и делегированное разрешение Exchange Online `IMAP.AccessAsUser.All`. Запусти `.venv/bin/python mailbox_sync.py`, пройди вход на странице Microsoft по коду из терминала и перезапусти бота. Помощник записывает refresh token в локальный `.env`; приложению нужен доступ к файлу для ротации. Доступность IMAP и пользовательского согласия определяется политикой университета. [Инструкция Microsoft](https://learn.microsoft.com/en-us/exchange/client-developer/legacy-protocols/how-to-authenticate-an-imap-pop-smtp-application-by-using-oauth)
- `MAIL_SENDERS` — точные адреса отправителей или домены через запятую. Изначально выбраны `isu.ifmo.ru,isu.itmo.ru`. Для папки, куда уже отфильтрованы нужные письма, можно поставить `MAIL_SENDERS=*`. При значении `*` бот получит доступ ко всем письмам выбранной папки.

Первая проверка показывает имеющиеся письма в приложении без рассылки истории (первая страница ИСУ и подходящие сообщения среди последних 20 писем IMAP). Затем раз в минуту проверяются новые сообщения. Признак обработки и очередь отправки сохраняются в SQLite. Копии одного письма в ИСУ и email учитываются как два источника. Переключатель «Пересылать в Telegram» управляет доставкой в чат. Mini App показывает до 100 последних сохранённых писем. Вложения открываются в исходной почте. Для больших писем IMAP загружаются первые 2 МиБ сообщения.

## Сервер друга

1. Клонируй репозиторий под отдельным пользователем Linux, подготовь `.env` с правами 600 и зависимости, как описано выше. На минимальной системе потребуются системные зависимости Chromium, их можно установить через `.venv/bin/python -m playwright install --with-deps chromium`. Рабочая папка и `data/` должны принадлежать пользователю службы. При миграции копируй базу остановленного бота, чтобы получить согласованную копию.
2. Для первого входа на сервере без рабочего стола подключись по SSH с X11 forwarding и локальным X-сервером. На Mac подойдёт XQuartz. Под тем же пользователем, который будет запускать бота, выполни `.venv/bin/python connect.py itmo` и `.venv/bin/python connect.py isu`. Окно входа отобразится у тебя, профиль останется на сервере. Для повторного входа этим способом сначала останови службу.
3. Привяжи домен к серверу. В Caddy достаточно сайта вида `campus.example.org { reverse_proxy 127.0.0.1:8787 }` (в Caddyfile размести директиву между фигурными скобками на отдельной строке). Укажи реальный адрес в `MINI_APP_URL`. Приложение по умолчанию слушает только loopback.
4. Запускай `.venv/bin/python bot.py` как один долгоживущий процесс. Например, служба systemd для установки в `/srv/itmo-campus`:

```ini
[Unit]
Description=ITMO Campus
After=network-online.target
Wants=network-online.target

[Service]
User=campus
WorkingDirectory=/srv/itmo-campus
ExecStart=/srv/itmo-campus/.venv/bin/python /srv/itmo-campus/bot.py
Restart=on-failure
RestartSec=10
UMask=0077

[Install]
WantedBy=multi-user.target
```

Сохрани этот пример как `/etc/systemd/system/itmo-campus.service`, подставив своего пользователя и путь. После `sudo systemctl daemon-reload` и `sudo systemctl enable --now itmo-campus` открой кнопку приложения в личном чате и нажми **Профиль → Проверить подключения**. Время везде московское.

**Граница приватности.** Публикуются исходники и пустой `.env.example`. Рабочий `.env`, база с письмами и ФИО и оба профиля Chromium исключены из Git. Доступ к этим файлам на хосте имеет пользователь службы и администратор сервера. Для приватности от самого администратора нужен хост под твоим контролем.

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
```

В тестах используются локальные и вымышленные данные. Проверяются доступ только владельцу, сохранение и отмена выполнения заданий, пересылка новых сообщений, напоминания, недельный обзор и изменения в расписании.
